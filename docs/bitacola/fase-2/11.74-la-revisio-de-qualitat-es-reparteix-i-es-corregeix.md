# 11.74. La revisió de qualitat es reparteix i es corregeix

20/11/2026. Després de la fase 5, Pere demana una revisió crítica i una
valoració de qualitat. El resultat és 82,20/100: les 386 proves passen,
però es reprodueixen quatre defectes amb dependències simulades. La fase 5
havia tancat les regles d’estil, no aquesta verificació funcional addicional.

Pere encarrega un repartiment escrit entre Codex i Claude. El contracte i
l’estat viuen a `docs/pla-poliment/revisio-qualitat-repartiment.md`.
Claude assumeix meteorologia del domini, importació 3D després de destruir
el mapa i separació de responsabilitats de les classes grans. Codex assumeix
localitzador, validació FIRMS, memòria cau i proteccions del compilador.
Ningú no modifica els fitxers de l’altre ni descarta el working tree previ.

La part de Codex:

- `PointLocator` elimina les promeses fallides de la memòria cau, només si
  encara corresponen a aquella lectura. Les consultes concurrents continuen
  compartint petició. Tres regressions noves comproven els reintents de
  províncies, municipis i les lectures simultànies.
- FIRMS valida nombres finits, rangs geogràfics, FRP no negativa, dia i hora
  abans de construir una detecció. No converteix dades absents en zero.
  Una resposta només amb capçalera és legítimament buida; un conjunt de
  files totes invàlides falla per no afirmar falsament que no hi ha focs.
  Les files vàlides d’un conjunt mixt es conserven. Dinou casos nous.
- La memòria cau FIRMS té un màxim de 32 rangs, amb expulsió LRU. El TTL
  continua determinant frescor i les entrades retingudes encara poden
  servir de fallback quan falla FIRMS. Quatre proves de memòria cau i una
  de ruta verifiquen límit, ús recent i substitució.
- `strict` de TypeScript i `strictTemplates` d’Angular queden activats a la
  configuració compartida del web. Fonts i proves compilen sense afegir
  excepcions ni conversions; també la integració API que importa el model.

Passen les 147 proves de model i les 112 de l’API, ESLint, les comprovacions
de tipus i les compilacions. La integració completa espera la part de
Claude. La prova manual global i Sonar continuen a la fase 7.

Pere autoritza **commits per mòduls quan el pla complet estigui acabat i
verificat**. Codex els farà a la integració final, incloent la feina prèvia
pendent de comitejar. Encara no es commiteja mentre es treballa en paral·lel.
