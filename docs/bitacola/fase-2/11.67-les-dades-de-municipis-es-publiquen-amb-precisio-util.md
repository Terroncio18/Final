# 11.67. Les dades de municipis es publiquen amb precisió útil

20/11/2026. Fase 6 del pla de poliment.

Els municipis LAU de GISCO arribaven amb fins a quinze decimals, molt més enllà
de la precisió de la font cartogràfica i de l'ús del mapa. Es guarden les
coordenades geogràfiques amb sis decimals (uns 11 cm per unitat decimal; error
màxim de 5,6 cm en latitud), conservant qualsevol ordre extra de cada posició.
El generador aplica el mateix arrodoniment quan es tornen a preparar les dades.

Abans, els 81 fitxers municipals ocupaven 12.623.491 bytes; després, 8.091.206
(−35,9%). Els 165 fitxers de `web/public/data` baixen de 25.369.174 a
20.836.889 bytes (−17,9%). La mida gzip estimada del conjunt passa de
5.299.214 a 4.000.169 bytes (−24,5%). S'han validat 11.847 anells: cap queda
obert ni amb menys de tres vèrtexs diferents.

També es fa explícit que el cau de combustible és prescindible: si escriure-hi
falla amb `ENOSPC`, s'eliminen respostes antigues d'una en una i es reintenta;
si no n'hi ha o l'espai continua insuficient, la petició es completa sense
guardar la resposta. La prova simulada recupera espai amb una sola eliminació i
dos intents d'escriptura; amb el cau buit, un intent fallit no interromp el
càlcul. La còpia local tenia 39 fitxers i 4.687.683 bytes (mida mitjana:
120.197 bytes) abans del canvi; no s'ha pogut inspeccionar el cau desplegat.

El paquet inicial continua a 1,50 MB, per sota de l'avís de 1,60 MB, així que
no s'hi ha aplicat cap canvi.

La prova del límit de concurrència de `fuelGrid` ara espera fins que les dues
places estan ocupades abans de consultar un tercer domini; així no depèn de
l'ordre en què el sistema de fitxers resol les lectures. La suite de l'API
passa (74 proves).
